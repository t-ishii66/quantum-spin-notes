## この文書の方針

## 群とは何か

**群**（group）とは、集合と演算の組

```math
(G, \cdot)
```

で、次の4つの性質を満たすものである。

1. **閉包**： $a, b \in G$ ならば $a \cdot b \in G$ （演算の結果も集合の中にある）
2. **結合律**： $(a \cdot b) \cdot c = a \cdot (b \cdot c)$
3. **単位元**： $e \cdot a = a \cdot e = a$ を満たす元 $e$ が存在する
4. **逆元**： 各 $a$ に対し $a \cdot a^{-1} = a^{-1} \cdot a = e$ を満たす $a^{-1}$ が存在する

注意すべきは、 $a \cdot b = b \cdot a$ という**交換律**は要求されていないことである。交換律が成り立つ群を**アーベル群**、成り立たない群を**非アーベル群**と呼ぶ。回転は非アーベル群の典型例である。

### 身近な例

**例1：整数全体の加法群** $(\mathbb{Z}, +)$

足し算について群をなす。単位元は $0$ 、逆元は $-a$ である。交換律が成り立つのでアーベル群である。

**例2：3次元空間の回転**

回転全体は、合成を演算として群をなす。単位元は「何もしない回転」、逆元は「逆方向に同じ角度だけ回す回転」である。しかし回転の順序を入れ替えると結果が変わるので、非アーベル群である。

## 回転群 SO(3)

3次元空間の回転を行列で表すと、 $3 \times 3$ の実行列 $R$ で

```math
R^T R = I, \qquad \det R = +1
```

を満たすものの全体になる。第1の条件 $R^T R = I$ は「列ベクトルが互いに直交し長さ1」を意味し（直交行列）、第2の条件 $\det R = +1$ は鏡映を除くための条件である。

この行列の集合を $\mathrm{SO}(3)$ と書く。名前の由来は

- **S** = special（行列式が $+1$ ）
- **O** = orthogonal（直交）
- **3** = $3 \times 3$

である。 $\mathrm{SO}(3)$ は群の4条件を満たす。実際に確かめると

- **閉包**： 2つの回転の合成は回転である
- **結合律**： 行列の積は常に結合的
- **単位元**： 単位行列 $I$
- **逆元**： $R^{-1} = R^T$ （直交行列の逆行列は転置）

### パラメータの数え方

一般の $3 \times 3$ 行列には $9$ 個の成分がある。条件 $R^T R = I$ は何個の拘束を与えるか。左辺の $R^T R$ は常に対称行列になる。なぜなら

```math
(R^T R)^T = R^T (R^T)^T = R^T R
```

だからである。 $3 \times 3$ 対称行列の独立成分は対角 $3$ 個と上三角 $3$ 個の計 $6$ 個である。つまり $R^T R = I$ は $6$ 個の独立な拘束を与え、自由度は

```math
9 - 6 = 3
```

である。この3つの自由度は、回転軸の方向（2パラメータ）と回転角（1パラメータ）に対応する。

## ユニタリ群 SU(2)

$2 \times 2$ の複素行列 $U$ で

```math
U^{\dagger} U = I, \qquad \det U = +1
```

を満たすものの全体を $\mathrm{SU}(2)$ と書く。名前の由来は

- **S** = special（行列式が $+1$ ）
- **U** = unitary（ユニタリ）
- **2** = $2 \times 2$

である。第1の条件 $U^{\dagger} U = I$ は「列ベクトルが直交し長さ1」のユニタリ条件であり、 $\mathrm{SO}(3)$ の直交条件の複素版である。

### パラメータの数え方

$2 \times 2$ の複素行列は $4$ 個の複素成分、すなわち $8$ 個の実パラメータを持つ。条件を整理すると

- $U^{\dagger} U = I$ はエルミート行列の条件で、 $4$ 個の実拘束
- $\det U = 1$ は複素数の条件で、 $2$ 個の実拘束（実部と虚部）

ただし $\det U = 1$ の2個のうち1個は重複している。 $U^{\dagger} U = I$ の両辺の行列式を取ると $\vert \det U\vert ^2 = 1$ 、すなわち $\vert \det U\vert = 1$ が自動的に出る。これは $\det U = 1$ の「絶対値が1」という部分をすでに含んでいるので、 $\det U = 1$ が追加する独立な拘束は残りの「偏角が0」の1個だけである。したがって独立な拘束は $4 + 1 = 5$ 個で、自由度は

```math
8 - 5 = 3
```

となり、 $\mathrm{SO}(3)$ と同じ3つの自由度を持つ。これは偶然ではない（あとで見る）。

### 一般の SU(2) 行列の形

$\det U = 1$ とユニタリ条件を合わせると、 $\mathrm{SU}(2)$ の一般の元は

```math
U = \begin{pmatrix} a & -b^* \\ b & a^* \end{pmatrix}, \qquad \vert a\vert ^2 + \vert b\vert ^2 = 1
```

と書ける。ここで $a, b$ は複素数である。実パラメータで数えると $4 - 1 = 3$ 個の自由度であり、上の議論と一致する。

## SU(2) から SO(3) への対応

[NOTE4.md](NOTE4.md) で見たスピン 1/2 の回転演算子

```math
U(\theta, \mathbf{n}) = \cos\frac{\theta}{2}\,I - i\sin\frac{\theta}{2}\,\mathbf{n}\cdot\boldsymbol{\sigma}
```

は $\mathrm{SU}(2)$ の元である。ユニタリかつ行列式が $+1$ であることは直接確認できる。

この $U$ は状態ベクトル（スピノル）に作用して

```math
\vert \psi\rangle \;\longrightarrow\; U\vert \psi\rangle
```

と変換する。一方、ブロッホベクトル $\mathbf{r}$ の変換は

```math
\mathbf{r} \;\longrightarrow\; R(\theta, \mathbf{n})\,\mathbf{r}
```

で、こちらは $3 \times 3$ の回転行列 $R \in \mathrm{SO}(3)$ である。

つまり、1つの $\mathrm{SU}(2)$ の元 $U$ に対して、1つの $\mathrm{SO}(3)$ の元 $R$ が対応する。この対応を

```math
U \;\longmapsto\; R
```

と書く。

### 二重被覆：2対1の対応

ここで重要なのは、 $U$ と $-U$ が**同じ** $R$ に対応することである。

$-U$ を状態ベクトルに作用させると

```math
\vert \psi\rangle \;\longrightarrow\; -U\vert \psi\rangle = e^{i\pi}\,U\vert \psi\rangle
```

となる。これは $U\vert \psi\rangle$ と全体位相 $e^{i\pi}$ だけ異なる。全体位相の違いは測定で区別できない。任意の測定に対して

```math
\vert \langle\phi\vert (-U\vert \psi\rangle)\vert ^2
= \vert e^{i\pi}\vert ^2 \cdot \vert \langle\phi\vert U\vert \psi\rangle\vert ^2
= \vert \langle\phi\vert U\vert \psi\rangle\vert ^2
```

となり、確率が完全に一致するからである（[NOTE1.md](NOTE1.md) で導入した Born 則）。ブロッホベクトルは測定確率から決まるので、 $U\vert \psi\rangle$ と $-U\vert \psi\rangle$ はブロッホ球上で同じ点を指す。したがって、 $U$ と $-U$ は同一の空間回転を表す。

```math
U \;\longmapsto\; R, \qquad -U \;\longmapsto\; R
```

逆に、任意の $R \in \mathrm{SO}(3)$ に対して、対応する $\mathrm{SU}(2)$ の元はちょうど $U$ と $-U$ の2つだけである。この「2対1」の対応を**二重被覆**と呼ぶ。

### $2\pi$ 回転と $4\pi$ 回転

$\theta = 2\pi$ を回転演算子に代入すると

```math
U(2\pi, \mathbf{n}) = \cos\pi\,I - i\sin\pi\,\mathbf{n}\cdot\boldsymbol{\sigma} = -I
```

となる。単位行列に**戻らない**。しかし対応する空間回転 $R(2\pi, \mathbf{n}) = I$ なので、空間の回転としては元に戻っている。

$\theta = 4\pi$ を代入すると

```math
U(4\pi, \mathbf{n}) = \cos 2\pi\,I - i\sin 2\pi\,\mathbf{n}\cdot\boldsymbol{\sigma} = +I
```

となり、ようやく単位行列に戻る。

| 回転角 | $\mathrm{SO}(3)$ （ブロッホベクトル） | $\mathrm{SU}(2)$ （状態ベクトル） |
|--------|--------------------------------------|-----------------------------------|
| $0$ | $I$ （元の位置） | $+I$ |
| $2\pi$ | $I$ （元の位置） | $-I$ （符号反転） |
| $4\pi$ | $I$ （元の位置） | $+I$ （完全に元通り） |

これが、スピン 1/2 の粒子が $2\pi$ 回転で符号を変え、 $4\pi$ 回転で初めて元に戻る理由を、群論の言葉で述べたものである。

## 表現とは何か

上の議論を一般化するために、**表現**（representation）という概念を導入する。

群 $G$ の表現とは、 $G$ の各元 $g$ に行列 $D(g)$ を対応させる写像で、群の演算を保つもの

```math
D(g_1 \cdot g_2) = D(g_1)\,D(g_2)
```

を満たすものである。つまり「群の元を行列に翻訳する辞書」のようなものである。群の抽象的な構造を、具体的な行列の掛け算に落とし込むことができる。

### 具体例で見る

$z$ 軸まわりの $\pi/2$ 回転と $\pi$ 回転という2つの操作を考えよう。これらをスピン 1/2 の回転演算子（ $\mathrm{SU}(2)$ の2次元表現）で書くと次のようになる。

$z$ 軸まわりの $\pi/2$ 回転：

```math
U_1 = U(\pi/2,\, \hat{z})
= \begin{pmatrix}e^{-i\pi/4} & 0 \\ 0 & e^{+i\pi/4}\end{pmatrix}
= \frac{1}{\sqrt{2}}\begin{pmatrix}1-i & 0 \\ 0 & 1+i\end{pmatrix}
```

$z$ 軸まわりの $\pi$ 回転：

```math
U_2 = U(\pi,\, \hat{z})
= \begin{pmatrix}e^{-i\pi/2} & 0 \\ 0 & e^{+i\pi/2}\end{pmatrix}
= \begin{pmatrix}-i & 0 \\ 0 & i\end{pmatrix}
```

$U_1$ を2回続けて行うと $U_2$ になるはずである。実際に確かめると

```math
U_1 \cdot U_1
= \frac{1}{2}\begin{pmatrix}(1-i)^2 & 0 \\ 0 & (1+i)^2\end{pmatrix}
= \frac{1}{2}\begin{pmatrix}-2i & 0 \\ 0 & 2i\end{pmatrix}
= \begin{pmatrix}-i & 0 \\ 0 & i\end{pmatrix}
= U_2 \quad\checkmark
```

群の演算（回転の合成）が、行列の積として再現されている。これが「表現」の意味である。

### 同じ回転を異なる次元で表す

重要なのは、**同じ回転操作**を異なるサイズの行列で表現できることである。

上の $z$ 軸まわり $\pi/2$ 回転を、3次元の回転行列で書くと

```math
R_1 = R(\pi/2,\, \hat{z})
= \begin{pmatrix}0 & -1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1\end{pmatrix}
```

である。 $U_1$ は $2 \times 2$ 、 $R_1$ は $3 \times 3$ だが、表している物理的操作は同じ「 $z$ 軸まわり $\pi/2$ 回転」である。

スピン 1/2 の文脈では

- $\mathrm{SU}(2)$ の $2 \times 2$ 行列 $U(\theta, \mathbf{n})$ は、回転群の**2次元表現**（スピノル表現）——状態ベクトルに作用する
- $\mathrm{SO}(3)$ の $3 \times 3$ 行列 $R(\theta, \mathbf{n})$ は、回転群の**3次元表現**（ベクトル表現）——ブロッホベクトルに作用する

同じ「回転」という操作を、異なる次元の行列で表現しているのである。どちらの辞書を使うかは、何を回したいか（状態ベクトルか、空間ベクトルか）によって決まる。

### 2つの表現で同じ物理が出る

2つの表現は見た目が異なるが、物理的な予測は一致する。このことは [NOTE3.md](NOTE3.md) ですでに具体的に確かめている。

スピン状態 $\vert \psi\rangle$ に対して方向 $\mathbf{n}$ の測定を行うとき、結果が $+1$ になる確率は2通りの方法で計算できる。

**方法1：スピノル（2次元表現）で計算する。** Born 則を直接使う。

```math
P(+\mathbf{n}) = \vert \langle{+n}\vert \psi\rangle\vert ^2
```

これは $2$ 成分ベクトルの内積の計算である。

**方法2：ブロッホベクトル（3次元表現）で計算する。** 状態 $\vert \psi\rangle$ のブロッホベクトル $\mathbf{r}$ と、測定方向 $\mathbf{n}$ の間の角度 $\Theta$ を求め、

```math
P(+\mathbf{n}) = \cos^2\frac{\Theta}{2}
```

とする。これは $3$ 次元ベクトルの内積 $\mathbf{r}\cdot\mathbf{n} = \cos\Theta$ から求まる。

[NOTE3.md](NOTE3.md) では、方法1の結果を半角の公式で整理すると方法2の結果と一致することを、途中計算を省略せず証明した。つまり、スピノルの世界で内積を取っても、ブロッホベクトルの世界で角度を測っても、同じ確率が得られる。

これこそが「2つの表現が同じ物理を記述している」ことの具体的な意味である。表現の次元は異なるが、物理量（測定確率）は表現の選び方に依存しない。
