# PHYSICS5: ブロッホ球をスピンの表現として読むときの回転

## 目的

この文書は、Alice の黒い球をブロッホ球とスピン `1/2` の模型として読むとき、

- ブロッホ球は何を表しているのか
- 古典的な空間回転はその状態にどう作用するのか
- 球を縦に 180° 回すと、なぜ `|0\rangle` が `|1\rangle` に変わるのか
- 「古典スピンベクトル」と「ブロッホベクトル」は何が違うのか

を整理するためのメモである。

---

## 結論

結論を先に書く。

1. ブロッホ球は、スピン `1/2` の**量子状態**を表す図として読むのが自然である  
2. ブロッホ球内のベクトルは、各方向の測定期待値をまとめた **ブロッホベクトル** である  
3. これは見た目は古典的な矢印に似ているが、意味は「測定統計の要約」であって、古典的な実在ベクトルそのものではない  
4. それでも空間回転に対しては、ブロッホベクトルは古典ベクトルと同じように回転する  
5. したがって Alice が黒い球を古典的に回すと、対応するブロッホベクトルも回る  
6. 実験室固定の `z` 軸に対して `|0\rangle = |+z\rangle` と読んでいるなら、球を縦に 180° 回したあとにもう一度 `z` 軸測定すると、状態は `|1\rangle = |-z\rangle` に移っているので `Oops!` が出る

この文書の中心は次の二文で尽くせる。

**ブロッホ球はスピン状態の表現であり、空間回転はその状態に作用する。**  
**しかしブロッホベクトルは、古典的な小さな矢印そのものではなく、量子状態の測定統計を表している。**

---

## まず固定したい前提

この文書では

```math
|0\rangle \equiv |+z\rangle,\qquad
|1\rangle \equiv |-z\rangle
```
とする。  
つまり `|0\rangle`, `|1\rangle` は、**実験室に固定した `z` 軸** に対する二つの固有状態である。

したがって、

- `|0\rangle` は `z` 軸測定で必ず `Yay!`
- `|1\rangle` は `z` 軸測定で必ず `Oops!`

を返す。

この約束を採ると、球を空間的に回したときに「状態が変わる」ことは自然に読める。

---

## 1. ブロッホ球は何を表しているのか

ブロッホ球は、スピン `1/2` の量子状態を表す図である。  
純粋状態は球面上の一点として表される。

その状態に対応して

```math
\mathbf r=(r_x,r_y,r_z)
```
というベクトルを考える。  
ここで各成分は

```math
r_x=\langle \sigma_x\rangle,\qquad
r_y=\langle \sigma_y\rangle,\qquad
r_z=\langle \sigma_z\rangle
```
である。

つまりブロッホベクトルとは、

- `x` 方向に測ったときの平均
- `y` 方向に測ったときの平均
- `z` 方向に測ったときの平均

をまとめたものである。

したがって、ブロッホ球は「粒子の中に実在する棒の向き」を描いた図というより、

- その量子状態が各方向の測定に対してどう応答するか

を一つの幾何に圧縮した図だと理解するのが正確である。

---

## 2. 古典スピンベクトルとブロッホベクトルの違い

ここは混乱しやすいので、はっきり分けておく。

### 古典スピンベクトル

古典的なベクトルだと思うなら、それは

- 空間の中に本当にある向き
- 各方向成分が同時に実在している量

というイメージになる。

たとえば「小さな棒磁石がこっちを向いている」という絵である。

### ブロッホベクトル

ブロッホベクトルは、それとは少し違う。

- 量子状態を表すベクトル
- 各方向測定の期待値をまとめたもの
- 直接に“見えている実在の矢印”ではなく、測定統計の表現

である。

見た目は古典ベクトルとよく似ている。  
しかし意味は違う。

たとえばブロッホベクトルが `+z` を向いている状態では、

- `z` を測れば必ず上
- `x` を測れば半々
- `y` を測れば半々

である。

古典ベクトルなら「本当は `x`,`y`,`z` すべてに確定した成分がある」と思いたくなるが、量子状態はそうではない。  
ブロッホベクトルは、各方向に対する測定統計を最もコンパクトに書いたものだと理解するのがよい。

一言で言えば、

- 古典スピンベクトル: 実在する向き
- ブロッホベクトル: 量子状態の測定統計を表す向き

である。

---

## 3. それでも、なぜ古典回転で一緒に回るのか

ここで初学者が混乱しやすいのは、

- 意味は古典ベクトルと違うのに
- なぜ回り方は古典ベクトルと同じなのか

という点である。

答えは、スピン `1/2` の状態が空間回転に対してきちんと変換するからである。

物理的には、空間回転 `R` に対して状態は

```math
|\psi\rangle \longrightarrow U(R)|\psi\rangle
```
と変わる。  
これに対応して、ブロッホベクトルも 3 次元ベクトルのように回る。

したがって教育的には、

**ブロッホベクトルは意味としては量子状態の要約だが、空間回転に対しては古典ベクトルのように振る舞う**

と理解してよい。

---

## 4. Alice が球を古典的に回すと何が起きるか

Alice が黒い球を手で普通に回すとき、それは **古典的な空間回転** である。

もしこの黒い球をスピン状態の模型として読むなら、その空間回転に対応して

- ブロッホ球内の状態点
- あるいはブロッホベクトル

も一緒に回る。

したがって、「球を古典的に回しただけでは状態は変わらない」と考えるのは、スピン模型としては不正確である。  
正しくは、

- 球を回した
- それに対応してスピン状態も回った

と読むべきである。

---

## 5. 縦に 180° 回転すると、なぜ $|0\rangle$ が $|1\rangle$ になるのか

Alice が球を**縦に** 180° 回した場合を考える。  
ここでいう縦回転とは、左右方向の軸を回転軸として、`+z` と `-z` が入れ替わる回し方である。

最初に状態が

```math
|0\rangle = |+z\rangle
```
だとする。  
この状態はブロッホ球の北極に対応する。

縦に 180° 回転させると、北極は南極へ移る。  
したがって、実験室固定の `z` 軸に対して見れば

```math
|+z\rangle \longrightarrow |-z\rangle
```
となる。  
つまり位相を除いて

```math
|0\rangle \longrightarrow |1\rangle
```
である。

このあと、Alice がもう一度 **実験室固定の `z` 軸方向** を測れば、結果は

```math
\text{Oops!}
```
になる。

逆に最初が

```math
|1\rangle = |-z\rangle
```
なら、同じ縦 180° 回転によって

```math
|1\rangle \longrightarrow |0\rangle
```
となり、次の `z` 軸測定では `Yay!` が出る。

したがって、スピン模型として読むなら

**球を上下逆さまにする普通の空間回転だけで、$|0\rangle$ と $|1\rangle$ は入れ替わる。**

---

## Physics Note: なぜ「半分の角度」が出るのか

ここで気になるのは、

- ブロッホ球では状態点が空間回転と同じ角度だけ回って見える
- しかしスピン `1/2` の回転演算子には角度の **半分** が入る

という点である。

これは矛盾ではない。  
回っている対象が二つあるからである。

1. **状態ベクトル（スピノル）**  
2. **ブロッホベクトル**

スピン `1/2` の状態ベクトルは、空間回転 `\theta` に対して

```math
U(\theta,\mathbf n)
=
\exp\!\left(
-i\frac{\theta}{2}\,\mathbf n\cdot\boldsymbol{\sigma}
\right)
```
で変換される。  
ここに `\theta/2` が現れる。  
これが「スピノルは半角で回る」という話である。

しかし、その結果として得られるブロッホベクトル

```math
\mathbf r=
(\langle \sigma_x\rangle,\langle \sigma_y\rangle,\langle \sigma_z\rangle)
```
は、空間ベクトルと同じく **角度 `\theta` だけ** 回転する。

したがって

- 状態ベクトルの変換則には半角が出る
- ブロッホ球上で見える状態点は全角で回る

という二層構造になっている。

有名な結果として、

- 360° 回転すると、ブロッホベクトルは元に戻る
- しかし状態ベクトルは $|\psi\rangle \to -|\psi\rangle$ となる

という性質がある。  
さらに 720° 回転して初めて、状態ベクトルそのものも元に戻る。

ただし単独の量子状態については、$|\psi\rangle$ と $-|\psi\rangle$ は全体位相の違いにすぎず、測定統計は同じである。  
そのため、ブロッホ球だけを見ている限り、360° 回転で何も問題なく元に戻ったように見える。

要するに、

- **ブロッホ球で見える回転は全角**
- **スピノルの内部表現は半角**

である。

これはスピン `1/2` の本質的な特徴であり、物理ノートとして明示しておく価値が高い。

物語の中では、Alice たちはこの事実をまず数式から知ることになるだろう。

- 360° 回しても、状態ベクトルはまだ本当には元に戻っていない
- 720° 回して初めて、状態ベクトルそのものが元に戻る

しかし同時に、単独の測定結果だけを見ても、その違いは直接には分からない。  
ここにスピノルの不思議さがある。

つまり三人は、

- 「一周しただけでは、式の中ではまだ符号がひっくり返ったまま」
- 「でも観測だけでは、それが見えない」
- 「二周してやっと、本当に元の状態ベクトルに戻る」

という、量子論らしい奇妙だが秩序だった事実に出会うことになる。

---

## 6. では、なぜ「回しても同じ結果」に見える場合があるのか

ここで「じゃあ回しても同じ結果になると言っていたのは何だったのか」という疑問が出る。

答えは、**何を固定して何を回したか** の違いである。

### 実験室固定の `z` 軸で読む場合

- 球だけ回した
- 測定軸は実験室に固定したまま

なら、状態と測定軸の相対関係が変わる。  
したがって結果も変わりうる。

### 球と測定軸を一緒に回す場合

- 球も回した
- 測定軸も同じだけ一緒に回した

なら、相対関係は保たれる。  
したがって結果は変わらない。

この区別を明示しないと、

- 回したら `|0\rangle` は `|1\rangle` になる
- でも回しても同じ声が返ることもある

が矛盾して見えてしまう。

矛盾ではなく、比較している測定軸が違うのである。

---

## 7. 最後に一行で言うと

Alice の黒い球をスピン模型として読むなら、**古典的な空間回転そのものがブロッホベクトルに作用し、縦に 180° 回せば `|0\rangle` は `|1\rangle` に移る。**  
ただしブロッホベクトルは古典的な実在ベクトルそのものではなく、量子状態の測定統計を表すベクトルである。
