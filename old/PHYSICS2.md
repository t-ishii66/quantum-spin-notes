# STORY2: 実験からパウリ行列へ至る流れ

## 目的

この文書は、

- 実際にはどんな測定を考えるのか
- その測定で何が観測されるのか
- その結果を説明しようとすると、なぜパウリ行列が自然に現れるのか

を、**シュテルン・ゲルラッハ型の実験の流れに沿って**整理するためのメモである。

狙いは、最初から

```math
\sigma_x,\sigma_y,\sigma_z
```
を「便利な行列」として置くことではない。  
むしろ、

1. 実験事実を並べる
2. その事実を同時に説明できる最小の数学を探す
3. その結果としてパウリ行列が出る

という順番をはっきりさせることにある。

---

## 出発点: どんな実験か

まず、銀原子や電子のような粒子線を用意し、ある方向に不均一な磁場をかける。  
磁気モーメントを持つ粒子なら、磁場勾配によって進路が曲げられる。  
もし内部自由度が古典的な連続量なら、スクリーン上には連続的な帯が出てもよさそうに見える。

しかし実際には、たとえば `z` 方向に装置を向けると、粒子線は

- 上側のスポット
- 下側のスポット

の **2本にだけ** 分かれる。

ここからまず分かるのは、

- この内部自由度は、`z` 方向について測ると2値しか返さない
- 少なくともこの測定に関しては、粒子は二状態系として振る舞う

ということだ。

物理ではこの2値を

```math
\text{up along }z,\qquad \text{down along }z
```
あるいは

```math
|+z\rangle,\qquad |-z\rangle
```
と書く。

---

## 実験 1: `z` 軸方向の測定を定式化する

次に、最初の `z` 測定で上側に出た粒子だけを選び、そのままもう一度 `z` 方向で測る。

すると結果は、

- もう一度必ず上側

になる。下側を選んだなら、もう一度必ず下側になる。

この事実はとても重要で、ここから

- `z` 方向の測定には2つの特別な状態がある
- その状態では、結果が確率的ではなく確定的に出る

と考えたくなる。

そこで `z` 測定に対する2つの確定状態を

```math
|+z\rangle,\qquad |-z\rangle
```
と書く。

意味は単純で、

- 状態 $|+z\rangle$ なら `z` を測ると必ず「上」
- 状態 $|-z\rangle$ なら `z` を測ると必ず「下」

ということである。

### この2状態の関係はどう表すか

この2つは、同じ `z` 測定に対して互いに排反な結果を与える。  
つまり一方が「必ず上」を返す状態なら、他方は「必ず下」を返す状態であり、両者は完全に区別可能でなければならない。

量子力学では、この「完全に区別可能」を

```math
\langle +z|-z\rangle=0
```
という直交条件で表す。

さらに、それぞれを確率1の状態として扱うために

```math
\langle +z|+z\rangle=1,\qquad
\langle -z|-z\rangle=1
```
と正規化する。

したがって `z` 測定の固有状態は、まず

```math
\langle +z|+z\rangle=1,\qquad
\langle -z|-z\rangle=1,\qquad
\langle +z|-z\rangle=0
```
を満たす直交規格化基底として導入される。

### 測定と声を式で書く

ここで初めて、「`z` 方向の測定そのもの」を式で表したくなる。  
測定結果を数値 `+1` と `-1` に対応させると、`z` 測定演算子は

```math
\hat Z
= (+1)|+z\rangle\langle +z|
+ (-1)|-z\rangle\langle -z|
```
と書ける。

この式の意味は明快で、

- $|+z\rangle$ 成分には `+1` を返す
- $|-z\rangle$ 成分には `-1` を返す

ということだ。

実際、

```math
\hat Z|+z\rangle=|+z\rangle,\qquad
\hat Z|-z\rangle=-|-z\rangle
```
となる。  
つまり `z` 測定で聞こえる2つの声を、演算子の固有値問題として書けたことになる。

### 行列で書くと $\sigma_z$ になる

この2状態を基底に選べば、

```math
|+z\rangle=
\begin{pmatrix}
1\\
0
\end{pmatrix},
\qquad
|-z\rangle=
\begin{pmatrix}
0\\
1
\end{pmatrix}
```
と書ける。

この基底で $\hat Z$ を行列表示すると

```math
\hat Z=
\begin{pmatrix}
1&0\\
0&-1
\end{pmatrix}
```
となる。これがそのまま

```math
\sigma_z=
\begin{pmatrix}
1&0\\
0&-1
\end{pmatrix}
```
である。

したがって `\sigma_z` は、最初から神秘的な行列として現れるのではない。  
まず `z` 方向に二値の測定があり、その2つの確定状態

```math
|+z\rangle,\qquad |-z\rangle
```
を直交する基底として置き、その測定を式で書いたら自然に現れる行列が `\sigma_z` である。

### なぜこの2つで他の状態も書けるのか

ここで次の考え方を採用するのが自然である。

- この系は、各方向の測定に対して2値しか返さない
- したがってまずは、各方向に二つの確定状態を持つ**最小のモデル**として、2次元の状態空間を採用してみる
- 2次元空間では、独立な2つのベクトルがあればそれが基底になる

`|+z\rangle` と `|-z\rangle` は互いに直交するので独立であり、この2次元空間の基底として使える。  
したがって、この系の任意の状態は

```math
|\psi\rangle=\alpha|+z\rangle+\beta|-z\rangle
```
と表せる。

もちろん、ここで「各方向で2値だから論理的に必ず2次元である」と証明したわけではない。  
ここで採っているのは、**観測事実を矛盾なくまとめる最小の記述として2次元を試す**という立場である。  
そしてこの後、別方向の測定や回転との整合性を調べてもこの枠組みで十分だと分かるので、この2次元モデルを採用する。

ここで大切なのは、「自然界が `z` 軸を特別扱いしている」ということではない。  
そうではなく、一度 `z` 測定で得られた2つの固有状態を基底として採用すれば、同じ2準位系の他のどんな状態もその線形結合で表せる、ということである。

ここまでで、`z` 軸方向の測定については

1. 実験で2値が出る
2. 確定状態 $|+z\rangle, |-z\rangle$ を置く
3. それらは互いに直交すると表す
4. 測定演算子 $\hat Z$ を作る
5. その行列表現が $\sigma_z$ になる

という流れが完成する。

## 実験 2: 別方向で測ると、確定していたはずのものが揺らぐ

今度は、最初に `z` 方向で上側を選んだ粒子を、次に `x` 方向の装置へ入れる。

すると結果は、

- `x` 方向の上
- `x` 方向の下

がほぼ半々で出る。

さらに、そのあと `x` 方向で上だった粒子だけを選び、もう一度 `x` で測ると、今度は必ず `x` 上になる。  
ところが、その `x` 上の粒子をもう一度 `z` に戻して測ると、

- `z` 上
- `z` 下

がまた半々に戻る。

つまり実験事実は次のようになる。

1. `z` の直後に `z` を測れば結果は再現する
2. しかし `z` の直後に `x` を測ると結果は半々になる
3. しかも `x` 測定を挟むと、もとの `z` 情報は失われる

ここで「粒子は同時に `z` の値も `x` の値も持っている」と考えるのは苦しくなる。  
`z` を確定させたはずなのに、`x` を測ると半々になり、さらに `z` を壊してしまうからだ。

---

## ここから何を要請すべきか

この一連の結果を説明するには、少なくとも次の構造が必要になる。

1. 状態は2次元の複素ベクトルで表せる
2. `z` 方向測定には、2つの固有状態 $|+z\rangle, |-z\rangle$ がある
3. `x` 方向測定には、別の2つの固有状態 $|+x\rangle, |-x\rangle$ がある
4. $|+z\rangle$ は `x` 基底で見ると半々に分解される
5. `z` と `x` は同時には確定しない

`z` 方向については、すでに

```math
|+z\rangle,\qquad |-z\rangle
```
という直交基底と、それに対応する測定演算子

```math
\hat Z=\sigma_z
```
が手に入っている。  
しかもこの2つは2次元空間の基底になっているので、この空間のどんな状態も

```math
\alpha|+z\rangle+\beta|-z\rangle
```
の形で書ける。  
したがって次の課題は、「この同じ2次元空間の中で、`x` 方向測定に対応する**別の直交基底**を作れるか」である。

---

## なぜ `x` 方向には別の行列が要るのか

実験 2 より、$|+z\rangle$ は `x` 測定で半々を与えなければならない。  
ここで大事なのは、`x` 方向の状態を `z` 方向の状態と直交させることではない。  
そうではなく、

- `x` 方向にも二値測定がある
- したがって `x` 方向にも2つの確定状態 $|+x\rangle, |-x\rangle$ がある
- その2つは互いに直交しなければならない
- しかも $|+z\rangle$ を `x` で測ると、2つの結果が半々に出なければならない

という条件を同時に満たす必要がある。

つまり、ここでやることは

- `z` 基底とは別に
- しかし同じ2次元空間の中で
- `x` 測定のための新しい直交基底を作る

ことである。

この条件だけなら、`z` 基底で半々に見える状態にはまだ位相の自由度が残る。  
したがって、ここで次の形を採るのは「実数係数で書ける基準方向をまず `x` と呼ぶ」という**位相規約の選択**である。  
その規約のもとでは、`z` 基底で見たとき

```math
|+x\rangle=\frac{1}{\sqrt 2}
\begin{pmatrix}
1\\
1
\end{pmatrix},
\qquad
|-x\rangle=\frac{1}{\sqrt 2}
\begin{pmatrix}
1\\
-1
\end{pmatrix}
```
のようになる。  
これはベクトルとして書けば

```math
|+x\rangle=\frac{1}{\sqrt2}\left(|+z\rangle+|-z\rangle\right),\qquad
|-x\rangle=\frac{1}{\sqrt2}\left(|+z\rangle-|-z\rangle\right)
```
ということである。

後で見るように、もっと一般には

```math
\frac{1}{\sqrt2}\left(|+z\rangle+e^{i\phi}|-z\rangle\right)
```
の形をした半々状態があり、ここでの `x` はそのうち `\phi=0` を選んだものに対応している。

この2つは確かに

```math
\langle +x|-x\rangle=0
```
を満たすので、`x` 方向の2つの固有状態として直交している。  
しかも $|+z\rangle$ はこの `x` 基底で等しい重みを持つので、`x` 測定では上下が半々に出る。

したがって `x` 軸方向の状態とは、

- `z` 基底から作られた重ね合わせ状態であり
- その重ね合わせが新しい直交基底を作っている

と理解するのがよい。

この2つを固有状態に持ち、固有値を `+1,-1` に持つ演算子は

```math
\sigma_x=
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix}
```
である。

ここで重要なのは、$\sigma_x$ が「気分で選ばれた」のではなく、

- `z` 基底がすでにある
- その同じ空間の中に、`x` 用の別の直交基底を作る
- $|+z\rangle$ を `x` で測ると半々になる
- その新しい基底の固有値演算子を書き下す

という実験事実を一つにまとめると、この形が自然に立つという点である。

---

## さらに `y` を入れると複素数が避けられない

ここで初心者が必ず感じる疑問がある。

- `z` から見れば、`x` も `y` もどちらも直角方向である
- ならば `x` と `y` は、`z` 基底から見れば同じものではないか
- それなのに、なぜ `y` では複素数が必要になるのか

これはとても自然な疑問である。  
実際、`z` 方向にそろえた状態 $|+z\rangle$ を測ると、

- `x` で測っても半々
- `y` で測っても半々

になる。  
したがって、`z` 測定の統計だけを見ている限り、`x` と `y` は区別できない。

### まず一般の「半々状態」を書く

`x` 方向の状態は

```math
|+x\rangle=\frac{1}{\sqrt2}\left(|+z\rangle+|-z\rangle\right),\qquad
|-x\rangle=\frac{1}{\sqrt2}\left(|+z\rangle-|-z\rangle\right)
```
と書けた。  
ここで重要なのは、$|+z\rangle$ と $|-z\rangle$ が

- 同じ重みで入っていること
- そのあいだの相対位相が `+1` または `-1` であること

である。

ところが、「`z` から見ると半々」という条件だけなら、もっと一般に

```math
|\psi(\phi)\rangle=\frac{1}{\sqrt2}\left(|+z\rangle+e^{i\phi}|-z\rangle\right)
```
という状態も全部許される。  
どれも $|+z\rangle$ と $|-z\rangle$ を同じ割合で含むから、`z` 測定だけでは区別できない。

この時点では、$\phi$ はまだ「`y` 軸を表す角度」ではない。  
単に、絶対値 1 の複素位相

```math
e^{i\phi}
```
を使って、半々状態を一般に書いているだけである。

### ここで初めて、`\phi` を「赤道上の向き」と読む

しかし、`z` 測定では区別できないこれらの状態も、別方向の測定をすると区別できる。  
したがって $\phi$ はただの飾りではなく、`z` 軸に垂直な平面の中で「どちらを向いているか」を表す量だと読むのが自然になる。

ブロッホ球の言葉で言えば、これらはすべて赤道上の状態であり、$\phi$ はその赤道上の方位角になっている。

つまり `x` と `y` の違いは、

- $|+z\rangle$ の係数の大きさ
- $|-z\rangle$ の係数の大きさ

の違いではない。  
違いは、その2成分のあいだの**相対位相**にある。

### `x` は `\phi=0` の基準方向として選ぶ

この赤道上の状態のうち、まず

```math
\phi=0
```
を選んだものを `x` 方向と呼ぶことにする。  
すると

```math
|+x\rangle=\frac{1}{\sqrt2}\left(|+z\rangle+|-z\rangle\right)
```
となり、先ほどの形がそのまま出る。

この段階では、`x` は「赤道上の基準方向」として選ばれたのであって、まだ `y` は導入されていない。

### `y` は、`x` から 90 度回転したもう一つの横方向として要請される

空間には `x` だけでなく、それと直交するもうひとつの横方向 `y` がある。  
`x`,`y`,`z` の3方向を対等に扱いたいなら、赤道上で `x` から 90 度ずれた、もう一つの独立な横方向が必要になる。

ここで初めて、

- `x` は赤道上のある基準方向
- `y` はそこから 90 度回転した方向

という意味で、$\phi$ に幾何学的な意味が入る。

したがって `y` 方向に対応する状態は、`x` に対して位相を 90 度ずらした

```math
\phi=\frac{\pi}{2}
```
の場合、すなわち `z` 基底で

```math
|+y\rangle=\frac{1}{\sqrt 2}
\begin{pmatrix}
1\\
i
\end{pmatrix},
\qquad
|-y\rangle=\frac{1}{\sqrt 2}
\begin{pmatrix}
1\\
-i
\end{pmatrix}
```
すなわち

```math
|+y\rangle=\frac{1}{\sqrt2}\left(|+z\rangle+i|-z\rangle\right),\qquad
|-y\rangle=\frac{1}{\sqrt2}\left(|+z\rangle-i|-z\rangle\right)
```
という2状態である。

ここで大切なのは、これはまだ「定義したから正しい」という話ではないことだ。  
この段階では、

- `x` を赤道上の基準方向に取る
- そこから 90 度回転したもう一つの横方向を `y` として要請する
- その候補を上の2状態で表す

という**仮説**を立てているにすぎない。

したがって本来の態度は、

- この要請が実験事実と合うか
- 回転対称性と矛盾しないか
- 後で導かれる交換関係や測定統計と整合するか

を調べ、もし不都合があればこの候補は却下する、というものである。  
つまり `\phi=\pi/2` は、最初から特権的に与えられているのではなく、自然な候補として提案され、整合性チェックを通って採用される。

では実際に、最も基本的な測定統計を確かめてみよう。  
例えば `|+x\rangle` を `y` で測ると、

```math
\langle +y|+x\rangle
=
\frac{1}{\sqrt2}(1,-i)\cdot \frac{1}{\sqrt2}
\begin{pmatrix}
1\\
1
\end{pmatrix}
=\frac{1-i}{2}
```
なので

```math
\left|\langle +y|+x\rangle\right|^2
=
\left|\frac{1-i}{2}\right|^2
=\frac12
```
となる。  
同様に

```math
\left|\langle -y|+x\rangle\right|^2=\frac12
```
であり、`|+x\rangle` は `y` 測定でも半々に分かれる。  
逆に `|+y\rangle` を `x` で測っても

```math
\left|\langle +x|+y\rangle\right|^2
=
\left|\langle -x|+y\rangle\right|^2
=\frac12
```
となる。  
つまり `x`,`y`,`z` のどの2方向を選んでも、一方の固有状態を他方で測れば半々になる。  
この対称性は、`y` を `\phi=\pi/2` の候補として選ぶことが、少なくとも基本的な測定統計と矛盾しないことを示している。

これらも `z` 基底では両成分を同じ重みで含む。  
だから `z` から見れば、`x` 方向の状態と同じく「半々」に見える。  
しかし `x` と違うのは、相対位相が $\pm 1$ ではなく $\pm i$ になっていることだ。

つまり

- `x` 方向は「半々 + 同位相」
- `y` 方向は「半々 + 90度ずれた位相」

として区別される。

ここで `i` が出るのは、いきなり思いつきで選んだ数だからではない。  
一般の位相

```math
e^{i\phi}
```
を持つ赤道状態の中で、`x` から 90 度回転した方向を表すものを取ると

```math
e^{i\pi/2}=i
```
になるからである。

### なぜ実数では足りないのか

もし係数を実数に限ってしまうと、相対位相として表せるのは実質的に

- `+1`
- `-1`

だけである。  
それでは `x` 方向は書けても、`y` 方向に必要な

- `+i`
- `-i`

という位相差を表現できない。

言い換えると、実数だけでは

- `z` から見て半々に見える横方向

を一種類しか区別できない。  
三次元空間の中で `x` と `y` を本当に別の方向として立てるには、複素数が必要になる。

この2状態を固有状態に持つ測定演算子が

```math
\sigma_y=
\begin{pmatrix}
0&-i\\
i&0
\end{pmatrix}
```
である。  
したがって `\sigma_y` は、ただ「もう1個必要だから足した行列」ではない。  
`x` と `y` の違いを相対位相として表そうとすると、自然に現れる行列である。

したがって、`y` 方向まで含めて三次元空間の回転と整合するように二状態系を記述しようとすると、

- `x` と `y` の違いを表すために相対位相が必要
- そのためには実数だけでは足りず、複素数が必要
- 3つの測定方向に対応して 3 つの特別な行列が必要

となり、その行列が

```math
\sigma_x,\sigma_y,\sigma_z
```
になる。

---

## なぜこの3つが「スピン成分」になるのか

空間を回転させたとき、`x`,`y`,`z` の測定は互いに移り変わる。  
したがって、対応する演算子たちも回転の下で一つの三成分ベクトルのように振る舞ってほしい。

そのためには、これらは角運動量と同じ交換関係

```math
[S_i,S_j]=i\hbar\epsilon_{ijk}S_k
```
を満たすべきである。

2次元表現を探すと、

```math
S_i=\frac{\hbar}{2}\sigma_i
\qquad (i=x,y,z)
```
と置けばちょうどよい。  
しかも 2 次元では、この交換関係を満たすエルミート行列の組は、基底変換を除けば本質的にこの表現に限られる。  
したがって、パウリ行列はスピン 1/2 の最小表現になっている。  
実際、

```math
[\sigma_i,\sigma_j]=2i\epsilon_{ijk}\sigma_k
```
が成り立つので、

```math
\left[\frac{\hbar}{2}\sigma_i,\frac{\hbar}{2}\sigma_j\right]
=i\hbar\epsilon_{ijk}\frac{\hbar}{2}\sigma_k
```
となる。

つまりパウリ行列は、

- 二値測定を表すだけの記号

では終わらない。  
それらはそのまま、スピン `1/2` の3方向成分を与える最小の表現になっている。

---

## 物語としての一番自然な筋

ここまでを物語の順番としてまとめると、流れは次のようになる。

1. `z` 方向のシュテルン・ゲルラッハ実験で、結果が2値しか出ない
2. 同じ方向の再測定で結果が確定的に再現される
3. しかし別方向 `x` で測ると、さっき確定したはずの状態が半々に崩れる
4. したがって状態は単なる古典的ラベルではなく、2次元状態ベクトルで表す必要がある
5. `z` 測定を表す最初の行列として `\sigma_z` が立つ
6. `x` 測定を同じ枠組みで表そうとすると `\sigma_x` が立つ
7. 三次元空間の対称性まで要求すると `y` 方向も必要になり、`\sigma_y` が立つ
8. その3つは回転の生成子としてまとまり、スピン `1/2` の演算子になる

この意味で、パウリ行列は

- 先に数学があって後から物理を貼る道具

ではなく、

- シュテルン・ゲルラッハ実験の事実を最小限で矛盾なくまとめたら現れる道具

だと見るのがよい。

---

## 最後に一行で言うと

パウリ行列が自然に出るのは、

**「3次元空間の中で、各方向について二値しか返さない量を持つ粒子を、回転と両立する形で記述したい」**

という要請を最小の2次元複素空間で実現すると、それがちょうどパウリ行列になるからである。
